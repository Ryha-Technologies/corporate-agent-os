# Examples

Worked, **illustrative** walkthroughs showing which workflow runs, what the project workspace looks like after each stage, and what a gate verdict and ledger look like. They are specifications of expected shape with placeholder values in angle brackets. They are not records of real runs, and they contain no real research figures, customer quotes or competitor data.

| Example | Workflow(s) | Shows |
|---|---|---|
| `startup-from-idea/` | business-validation → idea-to-business | Intake, ledger, task contract, discovery and opportunity gates, a "test first" decision |
| `saas-product/` | product-discovery → product-design → software-development → security-review | PRD slice, states matrix, architecture ADR, build gate verdict with re-run commands |
| `marketplace/` | idea-to-business with two-sided specifics | Two-sided problem statements, trust and fee modelling, differentiated design direction |
| `existing-product-improvement/` | product-maintenance | Four parallel audits, consolidated roadmap, maintenance plan |

To turn any example into a real run: install the system in a project, paste the brief from the example's `00-intake/brief.md`, and let the orchestrator produce real artefacts. Compare them to the shapes here.

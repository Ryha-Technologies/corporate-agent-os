# Claude Code adapter

Installs Corporate Agent OS into a Claude Code project. Formats verified against code.claude.com documentation on 2026-11-18 (see `research/source-register.md` S14, S15).

## What is shipped

| Component | Source here | Installed to | Claude Code feature |
|---|---|---|---|
| Skills | `../../skills/` | `.claude/skills/<name>/` | Skills (`/skill-name`, auto-invocation by description) |
| Sub-agents | `agents/*.md` (generated) | `.claude/agents/<id>.md` | Custom sub-agents via the Agent tool |
| Workspace instructions | `CLAUDE.md` | `CLAUDE.md` (or `CORPORATE-AGENT-OS-CLAUDE.md` if one exists) | Memory file |
| Project validators | `../../scripts/validate/` (subset) | `.corporate-agent-os/validators/` | Run manually or via your own hooks |

`agents/` is generated by `python scripts/package/build_adapters.py`. `model-map.yaml` maps the neutral model classes to Claude Code `model:` values (`inherit` by default).

## Install

```bash
python scripts/install/install.py --target claude --destination /path/to/project --dry-run
python scripts/install/install.py --target claude --destination /path/to/project
```

Personal scope (`~/.claude/skills`, `~/.claude/agents`) is available with `--scope user`; use it only if you want the skills in every project, since Codex-style skill-list budgets do not apply but context cost does.

## How the generated sub-agents use Claude Code features

- `tools`: mapped from the neutral tool set. Read → `Read, Grep, Glob`; write → `Write, Edit`; shell → `Bash`; web → `WebFetch, WebSearch`; delegation → `Agent`. Reviewers and executives receive no `Write`/`Edit`.
- `skills`: the agent's skills are preloaded in full when the sub-agent starts, so it does not depend on description matching. Trim the list in the YAML source if context is tight.
- `model`: `inherit` so cost is controlled at the session level. Change `model-map.yaml` to route `fast` roles to `haiku`.
- Combined sub-agent descriptions are kept short (≤ 200 characters each, enforced by the validator) to stay well under Claude Code's 15,000-token warning for agent descriptions.

## Skills portability note

The skill frontmatter uses only the six fields of the Agent Skills specification (`name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`), so the same folders also upload to claude.ai or package with Anthropic's `package_skill.py` without edits.

## Limits

- Claude Code does not enforce path-scoped writes; `write_scope` is an instruction verified by the `code-reviewer` sub-agent.
- `permissionMode`, `hooks` and `mcpServers` are not set in the generated files so they also work when loaded from a plugin (those fields are ignored for plugin sub-agents).
- No browser tool is built in; connect a browser MCP server in your own settings if design QA needs screenshots.
- A Claude Code plugin package (`.claude-plugin/plugin.json`) is not shipped in this version; see `docs/platform-compatibility-matrix.md`.

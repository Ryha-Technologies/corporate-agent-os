# Corporate Agent OS — Kiro Power

Version 0.2.0. Generated by `scripts/package/build_power.py`; do not edit here, edit `skills/` at the repository root and rebuild.

This power packages the 51 canonical Corporate Agent OS skills in the Agent Plugins 1.0.0 format that Kiro Powers use. Install it in Kiro with **Powers → Add Custom Power → Import power from a folder** (this directory) or **Import power from GitHub** (the repository URL plus this subfolder path). Kiro activates it when your request matches the keywords in `plugin.json`, or invoke a skill directly with `/skill-name`.

Created and maintained by Velluraju C (https://github.com/velluraju). MIT licence.

The power contains skills only. The orchestration agents, steering and hooks for Kiro are installed separately into your project's `.kiro/` directory by `python scripts/install/install.py --target kiro` because Kiro documents no power component for those.

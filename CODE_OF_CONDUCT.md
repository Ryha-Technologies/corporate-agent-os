# Code of conduct

We expect everyone contributing to or using this project to behave with respect and honesty.

- Be respectful. Disagree about ideas, not people. No harassment, discrimination or personal attacks.
- Be honest. Do not misrepresent what was tested, verified or sourced. The project's value depends on it.
- Be careful. Do not use this project to deceive customers, infringe rights, process personal data unlawfully, or test systems without authorisation.
- Be constructive. Report problems with reproduction steps; propose fixes with evidence.

Maintainers may remove contributions or contributors that violate these expectations. Reports go to the repository owner through the configured contact channel.

# Benchmark reports

One file per evaluation run: `<date>-<host>-<model>.md`, generated from `python evaluations/run_evals.py --report <path>` and then completed by the raters.

A report records only what ran. Items that did not run stay `NOT_RUN`. Reports are never edited after publication; corrections are new reports.

The build-time report `2026-11-18-build-validation.md` covers the repository's own validators and tests. It contains no benchmark scores because no model-driven run was executed in this build.

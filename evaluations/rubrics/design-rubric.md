# Design rubric

| Dimension | 0 | 1 | 2 | 3 | Evidence to cite |
|---|---|---|---|---|---|
| IA and flows | None | Screens without flows | Flows for main tasks | Flows with error/recovery, IA from goals, labels sourced | IA and flows documents |
| State completeness | Happy path only | Some states | Most states | Every cell of the states matrix specified or n/a with reason | States matrix |
| Visual intent | Template | Trend-following | Direction stated | Direction justified for category and audience, pattern-map comparison | Design rationale |
| Element purpose | Decoration everywhere | Some purposeless elements | Mostly purposeful | Every element has a stated job; fake data absent | Design QA |
| Accessibility | Not considered | Automated only | Automated plus manual with gaps | Per-criterion results, fixes, retests, deviations approved | Accessibility report |
| Responsive and motion | Not specified | Device-named breakpoints only | Content breakpoints | Content breakpoints, navigation changes, reduced motion | Responsive and motion specs |
| Implementation fidelity | Not reviewed | Reviewed from mockups | Rendered UI reviewed on one viewport | Rendered UI at representative viewports with screenshots | Design QA report |

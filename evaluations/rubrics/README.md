# Rubrics

Each rubric scores a deliverable 0–3 per dimension with anchors and names the evidence a rater must cite. A score without cited evidence is invalid. Raters are humans or a model that did not produce the work; self-scoring is not accepted.

| Rubric | Applies to |
|---|---|
| `behaviour-rubric.md` | Regression cases: did the agent behave as the case expects |
| `research-rubric.md` | Research briefs, evidence ledgers, competitor maps |
| `business-rubric.md` | Opportunity assessments, business models, strategy memos |
| `brand-rubric.md` | Brand strategy, naming, identity, brandbook |
| `design-rubric.md` | IA, flows, tokens, screens, design QA |
| `engineering-rubric.md` | Architecture, code, tests, documentation |
| `security-rubric.md` | Threat models, security reviews, privacy analysis |

Common scale: 0 = absent or wrong; 1 = present but generic, unsupported or incomplete; 2 = specific and supported with minor gaps; 3 = specific, supported, differentiated, verifiable. Dimensions not assessable from the evidence are marked N/A with the reason, never scored.

# Brandbook

Filled by: identity-designer. Reviewed by: brand-originality-auditor. A stranger must be able to produce on-brand work from this document.

1. **Brand foundation** — essence, positioning, audience, promise, proof (from brand strategy).
2. **Story and messaging** — narrative in three lengths; message hierarchy; prohibited claims.
3. **Logo system** — primary, secondary, symbol, wordmark, responsive variants; clear space; minimum sizes; backgrounds; monochrome and reverse; incorrect uses with examples; file inventory.
4. **Colour** — semantic roles; HEX/RGB (CMYK if print); tints; light/dark behaviour; usage ratios; contrast pairings table with measured ratios for text and controls.
5. **Typography** — families and licence records; weights; fallback stack; scale; line height; tracking; language and script coverage.
6. **Grid, spacing, layout, breakpoints.**
7. **Imagery and art direction** — subjects, framing, lighting, texture, composition; prohibited clichés; sourcing and rights rules.
8. **Illustration, iconography, data visualisation.**
9. **Motion** — timing, easing, purpose, reduced-motion behaviour.
10. **Voice and tone** — rules with sample copy; grammar and terminology.
11. **UI tokens and component usage** — link to design-tokens.json; examples.
12. **Applications** — website, product, mobile, presentation, social, email, documentation with real examples.
13. **Accessibility, localisation.**
14. **Distinctiveness** — comparison with the competitor pattern map; the one or two repeatable brand devices.
15. **Governance** — owner, approval, source of truth, asset inventory, version history.

## Acceptance
- [ ] Every text/control colour pairing has a measured contrast ratio meeting the target or is marked decorative-only.
- [ ] Every font, icon set, image and illustration has a licence record in asset-provenance.md.
- [ ] Misuse examples and real applications are present.

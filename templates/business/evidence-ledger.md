Rules
- Source type uses the hierarchy in `skills/research-intelligence/references/source-evaluation.md`.
- A row with source type "lead" cannot be the sole support for a consequential claim.
- Record what the source actually says, not what you hoped it said. If a source was unreachable write `UNVERIFIED` in the evidence column and keep the row.
- Capture key figures in the summary so the claim survives link rot.

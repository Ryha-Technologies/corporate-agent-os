# Traceability matrix

Filled by: test-engineer. Every acceptance criterion maps to at least one test and a result.

| Acceptance criterion id | Requirement | Test ids | Layer | Last result (PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE) | Evidence (report, log) | Date |
|---|---|---|---|---|---|---|

Rules: NOT_RUN is never converted to PASS; NOT_APPLICABLE needs a reason; a FAIL links to a defect id.

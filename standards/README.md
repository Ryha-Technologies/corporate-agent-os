# Standards

The quality bar each department's work is judged against. Standards are referenced by skills (what to do), gates (what evidence proves it) and rubrics (how reviewers score it). Each standard lists requirements, how they are verified, and the external references it draws on. External standards are cited, not reproduced; verify current versions via `research/source-register.md`.
